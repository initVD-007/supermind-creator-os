# Supermind Creator OS 🧠

An autonomous multi-agent AI platform designed for YouTubers and digital entrepreneurs. 

## 🚀 Current Progress: Phase 4 (AI Engineering Foundations)
We have successfully built a modular, production-grade full-stack architecture featuring:
- **Modular Backend:** FastAPI with separated routes, schemas, and services.
- **AI Brain:** Integrated Gemini 3 Flash for high-speed content generation.
- **Dynamic Frontend:** Next.js dashboard with independent AI Agent components.

## 🛠️ Tech Stack
- **Frontend:** Next.js 15, Tailwind CSS, TypeScript
- **Backend:** FastAPI (Python), Uvicorn
- **AI:** Google Gemini API (Flash Preview)

## 📂 Project Structure
- `/backend`: Python FastAPI logic, Pydantic models, and AI services.
- `/frontend`: Next.js application and modular UI components.

## 🚦 Getting Started
1. **Backend:** Navigate to `/backend`, activate `venv`, and run `uvicorn main:app --reload`.
2. **Frontend:** Navigate to `/frontend` and run `npm run dev`.
